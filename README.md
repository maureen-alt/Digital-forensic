## 📌 Knowledge Overview

### 1. Digital Forensics Basics

This module covers fundamental concepts and procedures essential for cyber incident response and digital investigations:

* **Chain of Custody:** Understanding evidence preservation, hashing algorithms (MD5, SHA-256), and integrity verification.
* **Evidence Acquisition:** Differences between volatile (RAM) and non-volatile (hard drive, SSD) data acquisition.
* **Legal & Regulatory Compliance:** Fundamentals of admissible digital evidence and documentation standards.

### 2. Autopsy Basics

Hands-on application of **Autopsy**, an industry-standard open-source digital forensics platform:

* **Case Management:** Creating forensic cases and ingesting disk images (`.raw`, `.dd`, `.E01`).
* **Ingest Modules:** Utilizing keyword search, web artifact analysis, hash lookup libraries (NSRL), and metadata extraction.
* **Timeline Analysis:** Analyzing system events, file creation/modification timestamps (MACB), and user activity logs.
* **Reporting:** Generating structured forensic analysis reports for legal or technical review.
